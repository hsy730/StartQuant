## 步骤详解

### Step 1：建立因子评估指标体系（1天）

#### 1.1 核心指标定义与解读

| 指标 | 计算公式 | 含义 | 优秀阈值 | 合格阈值 |
|-----|---------|------|---------|---------|
| **IC 均值** | $\frac{1}{T}\sum_{t=1}^{T} IC_t$ | 因子预测能力的平均水平 | > 0.05 | > 0.03 |
| **IC 标准差** | $\sqrt{\frac{1}{T-1}\sum(IC_t - \bar{IC})^2}$ | 因子预测能力的波动 | < 0.15 | < 0.20 |
| **ICIR** | $\frac{IC_{mean}}{IC_{std}}$ | 单位风险下的预测能力 | > 0.5 | > 0.3 |
| **IC 胜率** | $\frac{\text{IC}>0\text{的月数}}{\text{总月数}}$ | 因子方向正确的概率 | > 55% | > 50% |
| **IC 最大回撤** | 连续负IC的最大累计幅度 | 因子连续失效程度 | < 30% | < 50% |

#### 1.2 分层回测指标

| 指标 | 含义 | 优秀阈值 | 合格阈值 |
|-----|------|---------|---------|
| **多空年化收益** | 多头组减空头组的年化收益 | > 15% | > 8% |
| **多空夏普比率** | 多空收益的风险调整后收益 | > 1.0 | > 0.5 |
| **多空最大回撤** | 多空组合的净值最大回落 | < 15% | < 25% |
| **分层单调性** | 各组收益是否严格递增/递减 | 严格单调 | 近似单调 |
| **多头超额收益** | 多头组相对基准的年化超额 | > 8% | > 4% |

#### 1.3 辅助评估维度

- **换手率分析**：月均换手率 < 50% 为宜，过高则交易成本敏感
- **市值分布**：因子是否在特定市值区间失效
- **行业分布**：因子是否在某些行业系统性失效
- **市场阶段表现**：牛市/熊市/震荡市中的表现差异
- **与其他因子相关性**：|ρ| < 0.7 为宜，避免冗余

### Step 2：因子"体检"流程（2天）

#### 2.1 体检清单（Checklist）

对每个候选因子进行以下 10 项体检：

```
□ 1. IC 均值检验：|IC_mean| > 0.03？
□ 2. ICIR 检验：ICIR > 0.3？
□ 3. IC 胜率检验：胜率 > 50%？
□ 4. IC 稳定性检验：连续负IC不超过6个月？
□ 5. 分层单调性检验：5组收益单调或近似单调？
□ 6. 多空收益检验：多空年化收益 > 8%？
□ 7. 多空夏普检验：多空夏普 > 0.5？
□ 8. 换手率检验：月均换手率 < 50%？
□ 9. 市值检验：非小市值专属因子？
□ 10. 行业稳健性检验：在主要行业均有效？
```

#### 2.2 体检评分卡

| 检查项 | 权重 | 得分（0-10） | 加权得分 |
|-------|------|------------|---------|
| IC 均值 | 15% | | |
| ICIR | 20% | | |
| IC 胜率 | 10% | | |
| 分层单调性 | 15% | | |
| 多空收益 | 15% | | |
| 多空夏普 | 10% | | |
| 换手率 | 5% | | |
| 市值/行业稳健性 | 10% | | |
| **总分** | **100%** | | |

**通过标准**：总分 ≥ 70 分，且核心指标（ICIR、分层单调性）得分 ≥ 6 分

### Step 3：候选因子池构建（2天）

#### 3.1 批量生成候选因子

从以下维度批量构建 10-20 个候选因子：

**估值维度**：
- EP（市盈率倒数）
- BP（市净率倒数）
- SP（市销率倒数）
- DP（股息率）
- 改进EP（如扣非EP）

**质量维度**：
- ROE
- ROA
- 毛利率
- 现金流/利润比
- 盈利稳定性（ROE标准差倒数）

**动量维度**：
- 20日动量
- 60日动量
- 120日动量
- 动量加速度（动量的变化率）

**波动维度**：
- 20日波动率
- 20日振幅
- 下行波动率
- 特质波动率（残差波动率）

**流动性维度**：
- 20日换手率
- 20日成交额
- Amihud 非流动性指标

**成长维度**：
- 营收增长率
- 净利润增长率
- 预期增长率

#### 3.2 批量评估脚本

```python
def factor_screening(factor_list, data):
    """
    批量因子筛选
    """
    results = []
    for factor_name, factor_func in factor_list:
        # 计算因子
        factor_values = factor_func(data)
        
        # IC分析
        ic_stats = calculate_ic_stats(factor_values, data)
        
        # 分层回测
        layer_stats = calculate_layer_backtest(factor_values, data)
        
        # 综合评分
        score = scoring(ic_stats, layer_stats)
        
        results.append({
            'factor': factor_name,
            'ic_mean': ic_stats['mean'],
            'icir': ic_stats['icir'],
            'win_rate': ic_stats['win_rate'],
            'long_short_return': layer_stats['annual_return'],
            'long_short_sharpe': layer_stats['sharpe'],
            'monotonicity': layer_stats['monotonicity'],
            'score': score,
            'pass': score >= 70
        })
    
    return pd.DataFrame(results).sort_values('score', ascending=False)
```

## 常见问题

**Q1：ICIR 和 IC 均值哪个更重要？**
> ICIR 更重要。高IC均值但高波动的因子（低ICIR）实盘表现往往不佳。ICIR > 0.5 是较好的标准。

**Q2：分层单调性不严格怎么办？**
> 允许近似单调（如 Group1 < Group2 < Group4 < Group3 < Group5）。若完全混乱，说明因子与收益关系非线性或存在噪音。

**Q3：因子在小市值中特别有效，能用吗？**
> 需谨慎。小市值因子可能受流动性限制，实盘无法复制。建议分别测试大/中/小市值中的表现，或加入市值中性化。

**Q4：如何判断因子是否已经失效？**
> 观察近12个月的IC均值是否显著低于历史均值，或IC胜率是否跌破40%。若连续6个月IC为负，需警惕因子失效。
