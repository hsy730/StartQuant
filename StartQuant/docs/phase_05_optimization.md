# 阶段 5：迭代优化 —— 根据回测结果定位问题并调优

## 目标
基于回测结果进行诊断分析，定位策略问题根源，通过系统化方法进行迭代优化，形成可持续改进的策略开发流程。

持续进行

## 输出物

## 步骤详解

### Step 1：问题诊断框架（持续）

#### 1.1 收益端问题诊断

| 症状 | 可能原因 | 诊断方法 |
|-----|---------|---------|
| 年化收益过低（<5%） | 因子失效、信号弱、交易成本侵蚀 | 检查因子IC、对比纯因子分层收益与策略收益差距 |
| 收益不稳定（年化波动>25%） | 因子波动大、行业/市值集中 | 分析收益时间序列、检查持仓集中度 |
| 超额收益为负 | 因子方向错误、基准选择不当 | 对比策略与基准的净值曲线、检查因子方向 |
| 特定年份大幅跑输 | 因子在该年份失效、风格切换 | 分年度分析、对比因子在失效年份的IC |

#### 1.2 风险端问题诊断

| 症状 | 可能原因 | 诊断方法 |
|-----|---------|---------|
| 最大回撤过大（>30%） | 尾部风险暴露、止损缺失 | 分析回撤期间的持仓、检查是否有止损机制 |
| 回撤恢复时间过长 | 因子持续失效、市场风格不利 | 统计历史最大回撤及恢复时间分布 |
| 下行风险高（下行波动大） | 因子不对称性、左侧交易 | 分析盈亏比、检查收益分布偏度 |
| 极端行情表现差 | 缺乏极端行情保护 | 复盘2015、2018、2022等极端年份表现 |

#### 1.3 交易端问题诊断

| 症状 | 可能原因 | 诊断方法 |
|-----|---------|---------|
| 换手率过高（>80%/月） | 因子噪音大、调仓过于频繁 | 计算月均换手率、分析换仓原因 |
| 交易成本占比高（>30%收益） | 换手率过高、小市值股票多 | 对比毛收益与净收益差距 |
| 滑点影响大 | 流动性差的股票多、交易量大 | 分析持仓市值分布、日均成交额 |
| 无法成交（涨停/停牌） | 选股时未考虑流动性 | 检查选股逻辑中的流动性过滤 |

#### 1.4 诊断检查清单

```
收益端诊断：
□ 策略年化收益是否达到预期？
□ 超额收益是否稳定为正？
□ 是否存在特定年份/季度系统性失效？
□ 收益分布是否左偏（频繁小赚、偶尔大亏）？

风险端诊断：
□ 最大回撤是否可接受？
□ 回撤期间持仓是否有共同特征？
□ 是否存在尾部风险集中暴露？
□ 下行波动是否显著高于上行波动？

交易端诊断：
□ 月均换手率是否低于50%？
□ 交易成本占比是否低于20%？
□ 持仓股票平均市值是否足够大？
□ 是否存在流动性风险？

因子端诊断：
□ 近期IC是否显著低于历史均值？
□ 因子是否在某些行业系统性失效？
□ 因子间相关性是否稳定？
□ 是否存在风格漂移？
```

### Step 2：常见问题优化方案（持续）

#### 2.1 问题：因子近期失效

**诊断方法**：
```python
# 滚动IC分析
rolling_ic = ic_series.rolling(window=12).mean()
# 观察近12个月IC是否跌破历史均值-2倍标准差
```

**优化方案**：

1. **因子动态加权**
   ```python
   # 根据近期IC表现动态调整因子权重
   recent_ic_A = get_rolling_ic(factor_A, window=6)
   recent_ic_B = get_rolling_ic(factor_B, window=6)
   
   # 权重与近期IC成正比
   weight_A = max(recent_ic_A, 0) / (max(recent_ic_A, 0) + max(recent_ic_B, 0))
   weight_B = 1 - weight_A
   ```

2. **因子切换机制**
   ```python
   # 当因子IC连续3个月为负时，暂时停用
   if rolling_ic_A[-3:].sum() < 0:
       weight_A = 0
       weight_B = 1
   ```

3. **引入新因子**
   - 当现有因子集体失效时，引入不同类型的因子
   - 如价值因子失效时，增加动量或质量因子

#### 2.2 问题：换手率过高

**优化方案**：

1. **加入换手率惩罚**
   ```python
   def calculate_score(factor_value, turnover_penalty):
       """
       在因子得分中减去换手率惩罚项
       """
       base_score = factor_value
       penalty = turnover_penalty * expected_turnover
       return base_score - penalty
   ```

2. **持仓惯性**
   ```python
   # 上期持仓给予额外加分
   for stock in last_period_holdings:
       if stock in current_candidates:
           current_score[stock] += inertia_bonus
   ```

3. **延长调仓周期**
   - 从周度改为双周或月度
   - 引入"缓冲带"：排名变化需超过阈值才调仓

#### 2.3 问题：回撤过大

**优化方案**：

1. **加入止损机制**
   ```python
   def check_stop_loss(portfolio, date):
       """
       个股止损：亏损超过10%卖出
       """
       for stock in portfolio.holdings:
           cost_price = portfolio.get_cost(stock)
           current_price = get_price(stock, date)
           if current_price / cost_price - 1 < -0.10:
               portfolio.sell(stock, 'stop_loss')
   ```

2. **组合层面止损**
   ```python
   # 当组合净值从高点回撤超过15%时，减仓至50%
   if current_drawdown > 0.15:
       target_position = 0.5
   ```

3. **波动率控制**
   ```python
   # 根据近期波动率动态调整仓位
   recent_vol = get_recent_volatility(benchmark, window=20)
   if recent_vol > vol_threshold:
       position_size = base_position * (vol_threshold / recent_vol)
   ```

#### 2.4 问题：小市值暴露过多

**优化方案**：

1. **市值中性化**
   ```python
   # 在每个市值分层内分别选股
   for size_group in ['large', 'mid', 'small']:
       candidates = stocks[stocks['size_group'] == size_group]
       selected = select_top(candidates, n_per_group)
   ```

2. **市值约束**
   ```python
   # 排除市值最小的20%股票
   size_threshold = data['market_cap'].quantile(0.2)
   data = data[data['market_cap'] > size_threshold]
   ```

3. **市值加权而非等权**
   - 按流通市值加权，自然降低小市值影响

## 常见问题

**Q1：优化后回测变好，但担心过拟合？**
> 1. 确保优化逻辑有经济学含义，不是纯数据挖掘
> 2. 使用样本外测试验证
> 3. 简化优化参数，避免过度优化
> 4. 进行蒙特卡洛模拟检验稳健性

**Q2：策略实盘后表现不如回测？**
> 常见原因：
> 1. 滑点估计不足（实际滑点 > 回测假设）
> 2. 冲击成本（大单影响市场价格）
> 3. 停牌/涨停导致无法成交
> 4. 数据前视偏差（回测中使用了未来信息）
> 建议：回测时保守估计成本，加入更多约束

**Q3：如何判断策略是否已经失效？**
> 1. 近6个月IC均值显著低于历史（t检验）
> 2. 策略收益连续跑输基准超过3个月
> 3. 策略净值创历史最大回撤
> 4. 同类策略普遍失效（市场结构变化）
> 出现以上信号时，应暂停策略并重新审视假设

**Q4：优化到什么程度可以停止？**
> 优化应遵循"边际收益递减"原则：
> - 当再优化一项参数带来的夏普提升 < 0.05 时，可停止
> - 优先优化影响最大的参数（换手率、因子权重）
> - 保持策略简洁，避免过度复杂
