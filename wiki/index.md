# 内容目录

## 概念

- [[安全除法]] — 统一的除零与 NaN 保护入口，默认返回 None
- [[因子预处理四步顺序]] — 缺失值→去极值→中性化→标准化，顺序固定
- [[横截面SpearmanIC]] — 逐日横截面 Spearman 相关后取均值
- [[前视偏差判定]] — 以信号是否使用未来数据为准，而非 shift 方向
- [[评分归一与截断]] — 维度先映射到 0–100，总分再截断
- [[量纲一致性]] — 成本与收益同为比例，金额只在输出净值时换算
- [[单一真相源]] — 每类计算只留一个入口，其余模块调用
- [[智能默认与手动覆盖]] — 推荐参数附置信度与理由，用户可覆盖
- [[零波动率边界处理]] — 只把波动率依赖指标置 None
- [[版本快照与回滚]] — 变更留痕，回滚前先自动备份当前版本
- [[公式白名单沙箱]] — 只允许白名单函数与属性，编译期拒绝
- [[时序标准化避免前视]] — 标准化只用滚动窗口内的历史数据
- [[可交易性掩码优先]] — 加载阶段标记不可交易日，下游只传递
- [[缓存键与TTL失效]] — 键覆盖全部入参，过期以元数据判定
- [[智能自定义双模式面板]] — 智能给结论与理由，自定义给全部控制权
- [[横截面分位归因]] — 逐日计算分位阈值，禁止池化分组
- [[稳定性判定窗口]] — 至少两个完整窗口，不足即报错
- [[组合集中度与暴露]] — 行业/因子暴露与 Gini 集中度并看
- [[多Sheet导出约定]] — 五个 Sheet 固定顺序，名称即对外契约
- [[配置覆盖优先级]] — 用户显式配置优先于智能推荐
- [[挖掘检查点续跑]] — 按代持久化种群与前沿，可断点续跑
- [[策略信号与权重分离]] — 策略只出信号与权重，回测由基类统一
- [[Alpha101表达式因子库]] — 名称+表达式+描述三元组，按逻辑分类
- [[一键验证流水线]] — 阶段固定顺序，未来函数立即终止

## 实体

- [[FactorHub]] — 本地量化因子研究平台，FastAPI + React
- [[FactorPreprocessingPipeline]] — 因子预处理管道，三步流程单点实现
- [[WeightOptimizer]] — 六种组合权重方法的统一入口
- [[LookaheadBiasDetector]] — 未来函数统计检测器，五档风险等级
- [[ComprehensiveScoringService]] — 因子/策略/组合三套评分入口
- [[VectorBTBacktestService]] — 基于 vectorbt 的多模式回测服务
- [[RiskMetrics]] — 风险与收益指标的统一计算入口
- [[MiningAlgorithmRegistry]] — 挖掘算法工厂注册表，内置 5 种
- [[SmartPreprocessingDetector]] — 按数据特征推荐预处理配置
- [[FactorVersionService]] — 版本创建、对比、回滚与历史查询
- [[FormulaCompilerService]] — 公式树/表达式编译为可执行因子代码
- [[DataService]] — 行情取数、缓存与可交易性掩码构建
- [[CacheService]] — 缓存文件、元数据、TTL 与命中统计
- [[PreprocessingConfigPanel]] — 智能推荐与自定义两模式配置面板
- [[FactorAttributionService]] — 因子贡献与 alpha/beta 拆解
- [[FactorStabilityService]] — 分布/时序/滚动四类稳定性评估
- [[PortfolioAnalysisService]] — 暴露、集中度、风险与权重优化
- [[ExportService]] — 回测与对比结果的多 Sheet Excel 导出
- [[PreprocessingConfigAPI]] — 推荐、预设、校验三个端点
- [[挖掘任务与检查点模型]] — 任务状态表与逐代检查点表
- [[StrategyRegistry]] — 四个内置策略模板的注册与取用
- [[Alpha101FactorLibrary]] — 五类 Alpha101 表达式集合
- [[FactorOrchestrator]] — 七阶段验证流水线的编排实现
