## 一句话定义

系统依据数据特征推荐参数并给出置信度与理由，同时保留用户完全覆盖推荐值的通道。

## 核心要点

- 推荐流程固定五步：识别板块 → 分析分布定去极值方法 → 检测行业结构定中性化策略 → 评估样本量定最小样本要求 → 输出配置。
- 推荐结果包含 `config_dict`、`confidence`（0–1）、`reasoning`、`data_characteristics`、`warnings` 五部分，缺一不可。
- 判定因子使用可量化特征：偏度、峰度、异常值比例、是否肥尾、波动率是否时变、行业数量与最小行业样本量。
- 用户侧采用"智能(推荐) / 自定义"双模式：智能模式只读展示数据特征与推荐理由，自定义模式全参数可调并实时校验。
- 置信度低或存在警告时必须显式提示，不得静默套用推荐值。

## 适用场景 / 边界

- 适用：预处理参数、挖掘参数、回测参数的配置面板与 API 默认值。
- 边界：数据量过少或结构异常时推荐不可信，应退回保守默认并提示用户；推荐值只是起点，参数最终仍需由用户确认。
